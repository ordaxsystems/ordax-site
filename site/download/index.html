USAR NO WINDOWS · SEM PENDRIVE

OrdaX Desktop

Uma aplicação Windows com interface Native e serviços locais. Não substitui o Windows e não grava o disco como sistema operacional.

Homologação técnica · Windows x64

Instalador de avaliação

O Desktop já tem builds Windows com teste de instalação e atualização NSIS no GitHub Actions. Ainda não existe uma versão pública assinada e autorizada no catálogo OrdaX.

Consultar builds oficiais de homologação ↗

No GitHub, abra a execução bem-sucedida mais recente da branch main e procure o artefato ordax-os-desktop-dev-alpha-windows. O acesso aos artefatos pode exigir uma conta GitHub. A disponibilidade é temporária; não é um download público homologado.

Teste o produto real

  1. Baixe o artefato do build Windows aprovado e confira a revisão da execução.
  2. Extraia o instalador e instale no Windows x64; não é necessário preparar USB.
  3. Abra o OrdaX, percorra o primeiro uso e experimente a Surface, a Conta local e a Aura conforme os serviços disponíveis.
  4. Verifique o estado dos serviços e a atualização. Registre falhas observadas no computador, não apenas no CI.

Antes de instalar: o instalador de homologação ainda não é uma release pública com assinatura de distribuição. Não desative proteções do Windows para executá-lo. A Aura local e os aplicativos externos dependem de seus próprios gates e podem não estar totalmente disponíveis. Uma versão pública aparecerá apenas quando aprovada pelo publicador oficial.

O PRIMEIRO PASSO

OrdaX Creator

Um app para preparar seu USB.

O Creator seleciona uma release Stable autorizada, verifica seus arquivos e prepara o pendrive para iniciar o OrdaX.

Consultando disponibilidade pública

Os downloads aparecem aqui quando houver uma publicação autorizada.

Compatibilidade, tamanho e integridade acompanham cada arquivo publicado.

A release Stable
vai dentro do Creator.

Uma preparação guiada, do arquivo oficial ao primeiro boot.

  • Origem verificada

    A assinatura da release é conferida antes da preparação.

  • Integridade conferida

    Os arquivos e a mídia preparada passam por verificação.

  • O sistema roda pelo USB

    No MVP, você usa o OrdaX diretamente pelo pendrive.

EM TRÊS PASSOS

Do download ao primeiro boot.

SIMPLES. SEGURO. PORTÁTIL.
  1. 1

    Baixar o Creator

    Quando disponível, baixe o Creator compatível com seu computador pelo catálogo oficial.

    Os detalhes do arquivo acompanham a publicação.
  2. 2

    Conferir e preparar o USB

    Abra o Creator, selecione a release e confira a identidade e a capacidade do pendrive.

    A preparação apaga o conteúdo do USB escolhido. Confirme somente o dispositivo correto.
  3. 3

    Iniciar e usar pelo pendrive

    Depois da gravação e verificação, reinicie o computador e selecione o USB no menu de boot.

    O primeiro uso oferece conta e rede opcionais.
A preparação apaga o pendrive escolhido.

Salve seus arquivos antes. O Creator não oferece instalação no disco interno; a preparação não altera o SSD/NVMe/HD interno.

Entrar é opcional

Download e primeiro uso não exigem conta online.

Conhecer o acesso à conta ↗

Integridade antes da gravação

Assinatura, SHA-256 e tamanho vinculam a release aos arquivos oficiais. O Creator verifica esses dados antes de preparar o USB.
