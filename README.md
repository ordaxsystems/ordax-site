# OrdaX Site

Repositório proprietário da apresentação pública do OrdaX (`ordaxsystems/ordax-site`).

**Estado:** migração em desenvolvimento. Nenhuma publicação em produção está autorizada por este repositório.

A implementação original e os contratos canônicos permanecem em `ordaxsystems/ordax-os` até a conclusão e aprovação do cutover. Consulte a branch/PR de extração para o inventário, decisões e gates.

## Limites

O site apresenta marketing, downloads oficiais, documentos legais, entrada de Identity e Conta; não hospeda Surface, autenticação/OAuth, assinaturas, banco de dados nem release pipeline do OS. Funcionalidades inativas permanecem indisponíveis.
